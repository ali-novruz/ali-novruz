## 👋 About

Backend engineer from **Azerbaijan** 🇦🇿, building production-grade distributed systems on the JVM.

- 🏥 Currently building a **Remote Patient Monitoring System** — event-driven, Kubernetes-deployed, designed for resilient medical data flows
- 🧠 Working through **idempotent messaging**, the **transactional outbox + Debezium** pattern, and **saga-based recoverable workflows**
- 🧪 **Testcontainers-first CI** — integration tests against real Postgres, Redis and Kafka, not mocks
- 🌱 Going deeper on **JVM concurrency & performance tuning** (virtual threads, Kotlin coroutines)
- 💬 Ask me about Spring Cloud, Postgres index strategy, Redis Streams, or DDD boundaries
- 📫 Reach me at **alinovruz29@gmail.com** — open to backend / platform roles and collaboration

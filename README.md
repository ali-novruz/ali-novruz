## 👋 About me

Backend engineer working on **JVM performance, domain-driven design, and event-driven systems**.
Most of my time goes into making distributed services behave predictably under load — idempotent messaging, recoverable workflows, and data flows that survive partial failure.

- 🏥 Building a **Remote Patient Monitoring System** at production scale — Spring Boot, PostgreSQL, Redis, Kafka, Kubernetes
- 🧭 Focus areas: DDD · event-driven microservices · observability (Prometheus / Grafana) · CI/CD automation
- 🌱 Currently deepening: JVM concurrency & performance tuning, Kotlin coroutines, Postgres query planning
- 💬 Ask me about: Spring Cloud, Kafka delivery semantics, Redis patterns, Testcontainers-first CI
- 📫 Reach me at **alinovruz29@gmail.com** — open to backend / platform roles
